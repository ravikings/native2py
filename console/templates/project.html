Connect an agent

One URL, every client — every step below points at the same endpoint: 

{{ service.mcp_url }}
Claude Code (CLI)
  1. Run: claude mcp add --transport http {{ project.slug }} {{ service.mcp_url }}
  2. Restart Claude Code, or run /mcp in an active session, to pick up the new server.
  3. Confirm it connected: claude mcp list should show {{ project.slug }} as connected.
Claude Desktop
  1. Open Claude Desktop → Settings → Connectors → Add custom connector.
  2. Name it {{ project.slug }} and paste the URL above.
  3. Save — tools from this service appear in the composer's tool picker.
Codex CLI

Add to ~/.codex/config.toml:

[mcp_servers.{{ project.slug }}]
url = "{{ service.mcp_url }}"

Requires a Codex CLI version with remote HTTP MCP support — older versions only accept a local command.
