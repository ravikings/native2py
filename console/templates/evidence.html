HOW A RECIPIENT VERIFIES IT

Send them both files. They need Python 3.8+ and one package:

pip install cryptography
python3 verify_evidence.py evidence-{{ project.slug }}-....json

The verifier reads only the pack — no network, no database, no checkout of this repo. It prints the range, the builds that served it, and VALID or INVALID, then restates what the result does and does not mean.
